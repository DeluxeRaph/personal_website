# Raphael Nembhard Personal Site

A Rust + Axum personal site with a Windows 95-inspired interface.

## Run

```bash
cargo run
```

Then open <http://127.0.0.1:3000>.

## Edit Content

Most homepage and blog copy lives in `src/main.rs`. The styling lives in `assets/site.css`, and the circular profile image is `assets/avatar.png`.
